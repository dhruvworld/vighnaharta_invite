# વિઘ્નહર્તા આમંત્રણ

Personalize the Ganesh invitation with a guest name (Gujarati or English) and share it on WhatsApp.

## How to use

1. Open `index.html` in a browser (or serve the folder locally).
2. Type a name in the **સ્નેહી શ્રી** field.
3. Tap **WhatsApp પર મોકલો** to share the image, or **ડાઉનલોડ** to save it.

On phones, the share sheet lets you pick WhatsApp directly. On desktop, the image downloads and WhatsApp Web opens with the invite message.

## Local preview

```bash
npx --yes serve .
```

Then open the URL shown in the terminal.
